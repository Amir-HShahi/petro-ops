                    What the duplicate checks look for

                    Exact
                    The two files are byte for byte the same. Found when the file is submitted.
                    Near
                    The files differ but their normalized text is the same. Found after chunking.
                    Metadata variant
                    Same normalized text, different metadata recorded with it.
                    Overlap
                    Enough chunks repeat text of another item. A flag is a finding: both items are kept.
