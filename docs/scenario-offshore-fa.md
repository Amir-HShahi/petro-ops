# سناریوی مطالعه موردی: اپراتور نفت و گاز فراساحلی

## ۱. لایه‌ها

| لایه | نقش |
| --- | --- |
| لایه صفر | شرکت ملی نفت (راهبردی) |
| لایه یک | اپراتورهای منطقه‌ای، برای مثال اپراتور میدان گازی پارس جنوبی |
| لایه دو | میادین و سکوهای فراساحلی |
| لایه سه | تیم‌های بازرسی، تعمیر و نگهداری، حفاری و ایمنی (HSE) |
| لایه چهار (اختیاری) | آرشیو استانداردها، گزارش‌های حوادث گذشته و سوابق پرسنلی |

## ۲. دانش

**دانش عمومی:**
- گزارش‌های تحقیق حوادث، شامل Deepwater Horizon، Piper Alpha و Montara.
- هشدارهای ایمنی نهادهای نظارتی، مانند BSEE و HSE بریتانیا.
- مقالات فنی دسترس‌پذیر آزاد.

**دانش مصنوعی:**
- گزارش‌های بازرسی، گزارش‌های شیفت و پروفایل نیروها در قالب DOCX یا PDF.
- این اسناد را خودمان می‌نویسیم تا سناریوها تحت کنترل ما باشند.

## ۳. نگاشت پروژه بر سناریو

| مفهوم پروژه | نمونه در سناریو |
| --- | --- |
| مسئله (Issue) | خوردگی رایزر، خرابی مکرر پمپ، شکاف در یکپارچگی سد ایمنی |
| زیرمسئله (SubIssue) | بازرسی، تحلیل علت ریشه‌ای، گزینه‌های تعمیر |
| مجری (Executor) | مهندسان خوردگی، متخصصان کنترل چاه |
| RFP | برون‌سپاری مطالعه تحلیل خرابی یا کمپین بازرسی |
| بسته انتقال | خلاصه ریسک‌های یک سکو برای سطح منطقه‌ای و ملی |

## ۴. نقاط قوت

- سکوها واقعا دورافتاده و جدا از شبکه‌اند، پس رویکرد آفلاین توجیه طبیعی دارد.
- با منطقه خلیج فارس مرتبط است و برای پروژه دانشگاه خلیج فارس مناسب است.
- چارچوب ایمنی باعث می‌شود ارجاع به منبع و دروازه کیفیت داور اهمیت واقعی پیدا کند، چون ادعای بدون پشتوانه درباره خرابی سد ایمنی پیامد جدی دارد.

## ۵. نقاط ضعف

- داده‌های واقعی بازرسی اختصاصی‌اند، بنابراین بیشتر اسناد عملیاتی باید مصنوعی باشند. این موضوع ادعای «داده واقعی» را در رزومه ضعیف می‌کند.
- یادگیری واژگان تخصصی دامنه، مثل استانداردهای API و مدل‌های سد ایمنی، زمان می‌برد.

## ۶. جمع‌بندی

انتخابی محکم و قابل دفاع است، اما سناریوی فضایی روایت قوی‌تر و داده واقعی بیشتری دارد. اگر ارتباط محلی برای شما مهم‌تر از اصالت داده است، این سناریو را انتخاب کنید.
